# XBP plugin

Grok Build plugin packaging XBP agent skills (ops CLI, deploy engine, OCI registry, Cloudflare Workers setup).

Skills were sourced from the local Grok skills library (`~/.grok/skills/xbp`, `setup-xbp-deploy`) and live under `skills/`.

## Install

Via the XYLEX Group marketplace (`xylex-group/skills`) as plugin `xbp`.
