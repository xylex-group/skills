# Athena plugin

Grok Build plugin packaging Athena agent skills (auth, JS/Rust SDKs, billing, storage, workspace map).

Skills were sourced from the local Grok skills library (`~/.grok/skills/athena-*`) and live under `skills/`.

## Install

Via the XYLEX Group marketplace (`xylex-group/skills`) as plugin `athena`.
